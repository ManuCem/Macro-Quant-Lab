Macro Quant Lab

Experiments on how macroeconomics and machine learning meet quantitative trading. The whole lab is automated end to end with a Telegram bot and an n8n workflow.

Repository ↗ Live dashboard ↗

Was the VIX right about four market shocks? The VIX is the market's ~30-day volatility forecast, built from S&P 500 option prices. The study compares each day's VIX with the volatility that actually followed over the next 21 trading days, across the dot-com crash, 2008, Covid and the 2025 tariff shock.

~0.7 correlation

Predictive Pricing – AWS Data Pipeline

An automated AWS pipeline that turns messy, noisy data into an auditable pricing model, using Python and a SageMaker XGBoost model for asset valuation. It covers data engineering, schema reconciliation, hedonic pricing and cost control.

The source is the Amazon Laptop Messy Dataset (Kaggle): 10 fragmented CSV feeds with heavy missing data, non-standard units and formatting problems.

1 · Reconcile

Merged the 10 datasets into one consolidated schema on EC2.

2 · Extract

Pulled hardware attributes out of free text with regular expressions.

3 · Normalize

Fixed formatting problems to prevent data leakage and keep the model statistically valid.

4 · Columnar warehousing

Glue converts CSV to Parquet and enforces strict types, such as casting text prices to numeric floats.

The Parquet layout lets Athena scan about 90% less data through partition pruning, which cuts query cost and run time. The output was checked locally with TAD (Tabular Data Viewer) before modelling.
